# 0.1.0 预览版

本次发布基于2026-10-26桌面构建v31。

GitHub 包含可构建源码、模块、测试与四首演示音乐。完整便携版另带Python、ComfyUI、CUDA运行库与INT8音乐/封面、Whisper small、Qwen 0.6B；不带作者账号、设置、聊天、曲库、播放列表、生成缓存和旧环境。

ComfyUI源码与GPL许可随完整包保留，可直接修改；来源固定提交 e087d8f6cb7c6cdb11b59dc7c9bf17c79f8d877d。各Python分发包的许可保留在对应dist-info中；Electron第三方许可在程序目录。模型来源和许可见第三方组件文档，完整包另附模型卡和许可文本。

当前完整环境在RTX4090验证。需要兼容CUDA13的NVIDIA驱动；显卡驱动和语言模型服务账号由用户自行准备。其他GPU尚未完整验证。
