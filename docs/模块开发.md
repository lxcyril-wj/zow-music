# 模块开发

apiVersion=1，模块 JSON 独立维护。模块安装到 Data/modules，已有同名模块不覆盖；升级使用新 ID，旧任务固定原模块 ID。模块的版本、工作流和模型名与曲库独立。

## ComfyUI 模块

字段：id（英文小写与连字符）、version、kind（music/cover）、name、adapter=comfy、models、workflow、mapping。

mapping 将统一输入字段映射到工作流节点，例如 `"seed": [["2","seed"],["5","seed"]]`。标准音乐输入：lyrics/style/seed/seconds/steps/abc/prefix；封面输入：prompt/seed/prefix。

更换现有节点模型只需增加一份配置和工作流；新运行方式才需增加适配器。JSON 模块不包含任意 JS/Shell。用户导入的工作流会在其本地 ComfyUI 执行，应只安装可信来源节点。

工作流输出通过历史 outputs 中带 filename/subfolder/type=output 的文件读取。音乐优先MP3，封面PNG/JPG/WebP。任务保存 prompt ID 和提交标识，恢复先查原任务；提交不明确不自动重发。

文件前缀固定为 zow/<batch-id>/<song-id>/<stage>，不得使用任意外部绝对目录。成品下载到音乐库后不依赖 ComfyUI 输出。批次阶段完成调用 /free 的 unload_models 与 free_memory，只有队列空闲才执行。

## Python 校时模块

kind=asr/align，adapter=python，script 为模块目录下相对脚本。请求 JSON 包含 audio/lyrics/language/model/kind/output。进程只写任务缓存；主进程负责把时间轴存入曲库并防止覆盖手改。退出子进程释放模型。

Whisper 单次识别，保留实际唱词与词级时间；固定程序映射原词，不调用智能体复核、不自动反复识别。中文按需使用Qwen辅助，对齐结果只做基本时间格式检查。英文继续Whisper。

## 已知扩展点

远程生成服务、其它工作流的依赖自动安装、任意第三方Python模块的签名沙箱、模型仓库镜像和跨设备同步不属于当前0.1版。工作流模块可直接在设置导入；Python适配器由开发者随应用提供。
